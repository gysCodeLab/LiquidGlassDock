# Liquid Glass Dock 使用说明

当前版本：v1.66-preview（Windows x64，F 版玻璃）
更新日期：2026-11-22

---

## 一、启动

双击 `LiquidGlass.Desktop.exe` 即可。不需要安装 .NET、不需要管理员权限。

启动后会按**上次保存的状态**运行：

- 如果上次没开「接管系统任务栏」，Windows 任务栏照常在，Dock 只是浮在底部；
- 如果上次开了，Dock 会先把 Windows 任务栏藏起来再出现。

第一次使用（没有配置文件）默认**不接管任务栏**，可以放心双击。

### 几个入口的区别

| 入口 | 作用 |
|---|---|
| `LiquidGlass.Desktop.exe` | 按上次的状态启动 |
| `启动 Dock（隐藏任务栏）.bat` | 启动并接管任务栏（藏掉系统任务栏） |
| `切换任务栏.bat` | 一个开关：Dock 在跑就关掉它并恢复任务栏；没跑就启动并接管 |
| `恢复任务栏.bat` | 紧急恢复：不管 Dock 在不在跑，把 Windows 任务栏放回来 |
| `开机自启-开启.bat` / `开机自启-关闭.bat` | 开关「登录 Windows 后自动启动」 |

> 任务栏被藏起来后，恢复它最快的方式是：在 Dock 上点右键 → 取消「接管系统任务栏」。
> 如果 Dock 本身已经崩溃或没在运行，双击 `恢复任务栏.bat`。

整个文件夹可以整体拷到 U 盘或别的电脑。必须保留的只有两样：

- `LiquidGlass.Desktop.exe`
- `Shaders\Glass.hlsl`（玻璃材质着色器，运行时读取）

## 二、关闭

任选一种：

1. 在 Dock 上点鼠标右键 → **退出 Dock**（最快；任务栏会先恢复）
2. 双击 `切换任务栏.bat`
3. 命令行执行 `LiquidGlass.Desktop.exe --quit`

程序会先确认 Windows 任务栏已经回家，再退出。如果恢复不完整，会把恢复标记留在
`%LOCALAPPDATA%\LiquidGlassDesktop\shell-state.json`，下次启动继续补恢复。

重复启动不会开出第二个 Dock，会提示「已经在运行了」。

## 三、设置面板

在 Dock 上点右键 → **设置…**。所有开关都在这里，改完立即生效并写回配置。

### 停靠栏

- **显示 / 隐藏 Dock 快捷键**：点这一行右端的「▾」，直接选一个：
  - **鼠标双击**（默认）：在 Dock 玻璃空白处连点两下隐藏，再双击回来（两下在 0.5 秒内算一组）。
  - **鼠标三击**：同样位置连点三下隐藏，再连点三下回来。
  - **鼠标中键**：在 Dock 玻璃上按一下隐藏，再按一下回来。
  - **鼠标侧键（后退 / 前进）**：按侧键切换。
  - **自己按键录制…**：选完再按组合键。
  - 下拉里选「关闭快捷键」= 不绑定任何键；之后想用再进来选。
  - **所有方式都要求指针在 Dock 上**：鼠标手势本来就在 Dock 上点；键盘组合也只在指针位于 Dock 上时触发，所以在编辑器里按 `Ctrl+C` 复制、在浏览器里按快捷键都不会误收 Dock。
  - 被其他程序占用的组合键不会被接受：行内会提示「已被其他程序占用」，继续等你换一个。
  - 录制时按 `Backspace` 清除（关闭快捷键），按 `Esc` 取消；点到面板外面也会取消。
- **接管系统任务栏**：开启 = 藏掉 Windows 任务栏；关闭 = 立刻把任务栏放回来
- 显示开始按钮 / 显示运行中的程序 / 跟随任务栏固定项
- 悬停预览：鼠标停住多久后浮出窗口缩略图（0 = 关闭）
- 更换开始按钮图标 / 用账户头像 / 恢复默认图标
- **重新启动 Dock**：自动退出再拉起，任务栏设置保持不变
- **关闭 Dock 并恢复 Windows 任务栏**

> 快捷键只隐藏 Dock 本身，不会动 Windows 任务栏。Dock 被快捷键藏起来后，
> 将鼠标移回屏幕底部原来 Dock 所在的玻璃区域，再按一次同一个快捷键或使用同一个鼠标手势即可唤回。例如录制了 `Ctrl + M`，应先移动鼠标到该区域，再按键。
> 如果连快捷键也想不起来：运行 `LiquidGlass.Desktop.exe --quit` 关掉它，再双击启动。

### 小工具

- 启动台 / 文件资源管理器入口
- **显示时钟**：Dock 右端显示时间和日期（任务栏藏起来后也能看时间）
- 开机自启
- 现在打开启动台、打开系统快速设置

### 外观

- 玻璃通透度（几档可切）
- 玻璃折射开关（省电）

## 四、能做什么

| 功能 | 说明 |
|---|---|
| 液态玻璃面板 | 实时采样桌面 → 磨砂 → 边缘厚壁折射 → 色散 → 边缘高光 → 投影 |
| 接管任务栏 | 隐藏 Windows 任务栏，退出 / 崩溃时自动恢复 |
| 固定项同步 | Windows 任务栏钉了什么，Dock 上就有什么，顺序也一致 |
| 运行中应用 | 正在运行的程序出现在 Dock 上，点击切换 / 最小化，右键可关闭窗口或结束任务 |
| 悬停预览 | 停住鼠标浮出真实窗口缩略图 |
| 启动台 | 全屏浏览已安装应用，可键盘输入筛选 |
| 状态胶囊 | 网络 / 电量状态，点击打开系统快速设置（Win+A） |
| 时钟 | Dock 右端显示时间与日期，不参与图标放大 |
| 显示 / 隐藏快捷键 | 默认在 Dock 上双击收起 / 回来；可换成三击、中键、侧键或自己录的组合键（都要求指针在 Dock 上） |
| 鼠标靠近放大 | 指针附近图标连续放大，邻居随之带起 |
| 逐像素穿透 | 只有玻璃条和图标吃鼠标，其余位置点下去直接命中桌面 |
| 不干扰系统 | 不进 Alt-Tab、不抢焦点、不显示在任务栏 |
| 开机自启 | 登录后自动启动；可随时在设置里关掉 |
| 崩溃守护 | 单独的守护进程：Dock 意外退出会先恢复任务栏，再按限额重启 Dock |

## 五、数据与卸载

所有数据都在这个文件夹里：

```
%LOCALAPPDATA%\LiquidGlassDesktop\
├─ config.json        所有开关与玻璃参数
├─ app.log            运行日志（超过 512KB 自动轮转）
└─ shell-state.json   任务栏接管的恢复标记（正常退出后自动删除）
```

- **重置设置**：退出 Dock，删掉 `config.json`，再启动。
- **卸载**：退出 Dock（确认任务栏回来了）→ 在设置里关掉开机自启（或运行 `开机自启-关闭.bat`）→ 删掉程序文件夹和数据文件夹。
- 出问题先看 `app.log`，不要随手删 `shell-state.json`：它是「任务栏还没恢复」的标记，删了会让下次启动少补一次恢复。

## 六、已知限制

1. 面板常驻置顶，没有自动隐藏。
2. 空闲时并非零开销（静止约 30fps，单核 1% 左右），玻璃采样本身有成本。
3. 主要针对单屏 + 100% 缩放测试；多屏 / 高 DPI 已写适配逻辑，但未在所有组合上实测。
4. 单文件版内存约 130MB，属当前原型的正常水平。
5. 需要 Win10/11 + 支持 D3D11 的显卡；驱动太老会走降级路径，画面会变简单但不会崩。

## 七、命令行参数（日常用不到）

```
--quit                    关闭已在运行的 Dock
--restore-taskbar         只恢复 Windows 任务栏（Dock 不在也能用）
--toggle                  开关：Dock 在跑就关掉，没跑就启动并接管
--hide-taskbar            本次启动接管任务栏（不写回配置）
--switch-taskbar          只切换任务栏显隐，Dock 继续运行
--settings                打开设置面板
--launchpad               打开启动台
--safe-mode               不采样桌面，纯色底（排查采集问题）
--seconds N               N 秒后自动退出
--shot <路径>             截图到 BMP
```

其余开发向参数（`--lab`、`--sweep`、`--icons`、`--click`、`--dump-frame` 等）见源码。

## 八、从 GitHub 下载后怎么用（便携版）

本程序发布的是**便携版**，没有安装程序：

1. 下载 Release 里的 zip，解压到任意文件夹（不要在压缩包里直接双击）；
2. 双击 `LiquidGlass.Desktop.exe`；
3. 想用开机自启，运行一次 `开机自启-开启.bat`。

**更新**：关掉 Dock → 用新版本覆盖 `LiquidGlass.Desktop.exe` 和 `Shaders\` → 重新启动。
配置和数据都在 `%LOCALAPPDATA%`，覆盖程序不会丢设置。

**卸载**：见「五、数据与卸载」。
